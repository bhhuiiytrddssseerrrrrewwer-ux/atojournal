# Contributing

Thanks for your interest in improving Auto Trading Journal!

## How to Contribute
1. Fork the repository and create a feature branch from `main`
2. Run the app locally and add tests where applicable
3. Ensure lint and tests pass: `npm run lint && npm run test:run`
4. Open a Pull Request with a clear description and screenshots if UI changes

## PR Guidelines
- Keep changes focused and incremental
- Update or add tests for behavior changes
- Update docs (`docs/*.md`) when adding features or changing behavior
- Link related issues and describe rationale

## Commit Style
- Use clear, imperative messages: "Add", "Fix", "Refactor"
- Reference issues when relevant: `Fixes #123`

## Code Review
- Two approvals recommended; maintainer may merge
- Be responsive to feedback and keep discussions constructive

## Development
- See `docs/DEVELOPMENT.md` for local setup and scripts
